# Coordinates: punto de entrada para agentes

Biblioteca independiente de geometría para Kotlin/JVM; no incluye el SDK de Android ni un renderizador de imágenes. Estas guías describen el código actual de `main`. Las coordenadas del artefacto publicado y su versión solo figuran en [IMPORT.md](../../IMPORT.md); no supongas que main ya se ha publicado.
